TapPony 把任何 NFC 标签变成你自己服务器的一个按钮。碰一下 NFC 标签，手机就会发送你设计好的 HTTP 请求：Webhook、REST API 调用、表单提交或简单的 GET 请求。请求中包含标签的 UID、芯片信息以及写在标签里的 NDEF 内容，让 NFC 自动化变得简单直接。

它支持你从未写入过的 NFC 贴纸、卡片、钥匙扣和标签，所以你手上现有的门禁卡、工牌和标签都能立刻触发你的自动化流程。

无需账号。无需云端。没有追踪。请求直接从你的手机发送到你填写的 URL，你的配置、扫描记录和密钥都只保存在你的设备上。

<b>你可以用它做什么</b>
• 智能家居：门口的 NFC 标签一碰就能运行场景，或向你的智能家居服务器发送 Webhook
• 库存与资产管理：每件物品碰一下，即可记录到你的表格、数据库或 API
• 签到、考勤与安保巡更：每个巡检点放一个标签，服务器的返回结果直接显示在屏幕上
• 你自己的脚本：任何接受 HTTP 请求的服务器都能响应 NFC 扫描

<b>请求构建器</b>
• POST、GET、PUT、PATCH 或 DELETE
• 用 {uid}、{payload}、{timestamp} 等模板生成 JSON、表单或纯文本请求体
• 自定义请求头，支持 Bearer、Basic 和 API 密钥认证
• 可选 HMAC-SHA256 签名，方便服务器验证每个请求
• 常见 Webhook 配置的预设，创建后仍可编辑
• 每次触碰后查看服务器的返回内容，也可以让它朗读出来，无需动手

<b>NFC 读卡器</b>
• 按规范字节顺序读取标签 UID，芯片支持时还能读取芯片型号、签名和扫描计数器
• 读取 NDEF 文本和链接
• 规则可按 UID、类型、内容或你起的名字，把每个标签分配到对应的配置
• 批量模式，连续扫描大量标签
• 离线队列，恢复联网后按顺序发送扫描记录

<b>NFC 写入</b>
• 向标签写入链接、文本或标签自身的 UID
• 写入 TapPony 启动链接，即使应用已关闭，碰一下也能打开应用并发送请求
• 可选永久锁定，需二次确认

<b>快速访问</b>
• 快捷设置图块
• 为每个配置创建桌面快捷方式
• 可被其他自动化应用打开的 tappony://scan 链接

<b>隐私与安全</b>
• 明文 HTTP 只能发往你自己局域网内的地址，并且只有在该配置中手动开启后才可用
• 密钥使用手机硬件支持的密钥库中的密钥加密，不会出现在历史记录或导出文件中
• 扫描记录只保存在设备上，支持导出 CSV
• 没有广告，没有统计分析，无需账号

支持英语、德语、西班牙语、法语、巴西葡萄牙语、俄语和简体中文。
